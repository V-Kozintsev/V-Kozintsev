## Frontend

**От макета до работающего интерфейса.**

- **Вёрстка и UI:** адаптивные страницы по Figma, Flexbox / Grid, SCSS, SVG, состояния элементов и взаимодействия на мобильных устройствах.
- **Логика приложений:** компоненты, маршрутизация, управление состоянием, поиск и фильтрация, формы с валидацией и обработкой ошибок.
- **Данные и интеграции:** запросы к API, асинхронные состояния интерфейса, Firebase, локальное хранение и связка frontend с Laravel.

  <summary><strong>Как проверяю интерфейсы</strong></summary>

Повторяющиеся элементы выношу в общие компоненты. Проверяю типы, адаптивность и сценарии взаимодействия: загрузку, ошибки, пустые состояния и работу форм. Учитываю размер изображений, отложенную загрузку и поведение интерфейса на мобильных экранах; перед сдачей проверяю итоговую сборку.

</details>
